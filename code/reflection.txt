In this assignment, I learned how normalization works in normalize_name: before comparing names, 
it applies Unicode NFKD normalization, removes non-ASCII characters, lowercases the text, 
replaces non-alphanumeric characters with spaces, and filters out FILLER_WORDS. 
This matters because it standardizes inconsistent menu formatting before text matching.
 I also learned that fuzzy matching with token_sort_ratio in top_candidates only measures token similarity, 
 not actual product ingredients. 
 For example, “Matcha Latte” scores 87 against “Mocha Latte”, 
 so the threshold (AUTO_MATCH = 90) in match_band and a human in the loop are needed 
 because high text scores can still represent completely different drinks.
